📖 Miniguia de Estudos
1. Resumo do Tema

A Educação Financeira consiste no desenvolvimento de conhecimentos e hábitos que permitem administrar recursos financeiros de forma consciente. Seu propósito é auxiliar as pessoas a controlar gastos, evitar dívidas, criar reservas financeiras e planejar o futuro.

Os pilares fundamentais são:

Ganhar
Poupar
Multiplicar

Além disso, conceitos como orçamento, juros compostos, investimentos e consumo consciente são essenciais para uma vida financeira equilibrada.

2. Glossário
Conceito	Definição
Educação Financeira	Conhecimento para administrar recursos financeiros de forma consciente.
Orçamento	Controle de receitas e despesas.
Receita	Todo dinheiro recebido.
Despesa	Todo dinheiro gasto.
Superávit	Quando as receitas são maiores que as despesas.
Reserva de Emergência	Valor guardado para imprevistos.
Juros Compostos	Juros calculados sobre o valor inicial e os juros acumulados.
CET	Custo Efetivo Total de um empréstimo.
Liquidez	Facilidade de transformar um investimento em dinheiro.
Rentabilidade	Retorno obtido em um investimento.
